## merged cells 的业务规则

1. A 列合并表示一个星期块，不是课程。
2. C/D 列合并的行跨度表示连续节次。两行跨度对应 2 节，四行跨度对应 4 节。
3. 合并区域只有左上角保存值。遍历每个坐标会遇到 `MergedCell` 占位，必须只处理左上角一次。
4. 7 个 C 列空合并区域是结构化空课位，不能生成 Course。
5. `F22:F23` 位于课表列之外，是空格式残留。应忽略，必要时记录 metadata 或低等级 warning。
6. 一个非空合并区域不一定只包含一门课。`D8:D11` 等 5 个区域各包含 3 门同时间、不同周次课程。

## `parseWeekExpression()` 兼容策略

1. 保存 `rawWeekText`，再进行解析，不覆盖原文。
2. 统一全角/半角括号、中文/英文逗号、顿号、空格、换行和常见连字符（`-`、`–`、`—`、`－`）。
3. 从课程行中寻找**最后一个内容含“周”的括号段**。课程名本身可能含 `（二）`、`（三）`，不能取第一个括号。
4. 接受不匹配的左右括号。真实 `D22`、`D36` 使用 ASCII 左括号 `(` 和中文右括号 `）`。
5. 支持：
   - 区间：`1-16周`
   - 枚举：`1,3,5,7周`、`1，3，5，7周`、`1、3、5、7周`
   - 奇偶：`单周`、`双周`，需要由学期总周数展开
   - 多段：例如 `1-4,7-10周`，拆分后取并集并排序
6. 校验周数为正整数、起始不大于结束、且不超过 metadata 中的学期总周数；无法确认总周数时保留解析结果并发 warning。
7. 返回结构化结果，例如 `{ weeks, normalized, kind, raw, warnings }`，而不是只返回字符串。
8. 单个物理 cell 中出现多个课程/周次时，先由 `parseCourseBlock()` 分块，再分别调用 `parseWeekExpression()`。

# 教师解析

真实数据有两种教师表达：

1. 无标签第二行：`张宪义 A7-322`、`丛莉 A7-322`、`王海`。
2. 显式字段：`授课教师：冈田庸平` 或 `授课教师:小山贤一`。

统计：33 个课程项均可识别 teacher；其中 15 项使用显式“授课教师”，18 项使用无标签姓名行。真实文件没有 teacher 完全缺失的课程，但未来 parser 仍必须允许 `teacher` 为空。

## `extractTeacher()` 规则

1. 优先匹配 `授课教师\s*[：:]\s*(...)`，同时接受中英文冒号。
2. 显式字段只截取到 `学术导师` 或行尾，不把后面的导师并入 teacher。
3. 没有显式字段时，先从课程下一行尾部剥离已确认的教室，再将剩余非空短文本作为低风险候选教师。
4. `学术导师` 永远不能覆盖 teacher。
5. 不能把课程名、周次、`9人`、`体育3` 中的数字当作教师信息。
6. 无法确认时保留课程，令 `teacher` 为 `undefined` 并产生 `UNRECOGNIZED_TEACHER` warning。
7. 保存字段来源，例如 `teacherSource: 'explicit-label' | 'implicit-line'`，便于审计。

| 视觉设计 | 小山贤一 | 范迎南 | 5 |
| 角色造型 | 吉松大志 | 曹文瑞 | 5 |

# 教室解析

实际只出现两种教室：

| 教室 | 课程项数 | 出现位置 |
| --- | ---: | --- |
| `A7-322` | 24 | 课程行尾或无标签教师行尾 |
| `A6-320` | 8 | 无标签教师行尾 |
| 缺失 | 1 | `D20:D21` 体育3 |

## `extractClassroom()` 保守规则

1. 只在课程行尾、教师行尾或显式教室字段附近匹配，优先处理真实形态 `A6-320` / `A7-322`。
2. 当前可用保守模式近似为大写建筑字母 + 1～2 位楼号 + 连字符 + 3～4 位房号，例如 `[A-Z]\d{1,2}-\d{3,4}`，并要求合理边界或位于行尾。
3. 允许教室紧跟中文右括号；真实多课程行是 `（2-5周）A7-322`，中间没有空格。
4. 不因文本中含数字就认定为教室：`1-16周`、`9人`、`体育3` 都不是教室。
5. 不把任意姓名后的数字串、周次区间或班级人数转换成教室。
6. 无法识别时保留课程，令 `classroom` 为 `undefined` 并产生 `UNRECOGNIZED_CLASSROOM` warning。
7. 保留 `rawClassroomText` 或原始课程块，便于将来扩展其他楼栋格式。

# 推荐数据模型

建议把“课表列/班级元数据”“排课课程项”“来源定位”分开：

```ts
interface Course {
  id: string
  name: string
  cohortId: string
  dayOfWeek: 1 | 2 | 3 | 4 | 5 | 6 | 7
  startSection: number
  endSection: number
  weeks: number[]
  teacher?: string
  academicAdvisor?: string
  classroom?: string
  note?: string
  source: CourseSource
}

interface CourseSource {
  workbookName: string
  worksheetName: string
  cell: string
  mergedRange?: string
  blockIndex: number
  rawText: string
}

interface CohortMetadata {
  id: string
  column: string
  rawHeader: string
  className?: string
  studentCount?: number
}

interface TimetableRegion {
  worksheetName: string
  headerRows: number[]
  dayColumn: string
  sectionColumn: string
  cohortColumns: string[]
  firstScheduleRow: number
  lastScheduleRow: number
}
```

`studentCount: 9` 可以从 `（9人）` 解析，但必须保留 `rawHeader`。`cohortId` 不能只用班级名，因为 C3/D3 相同；应结合 C2/D2 或列坐标。

# 推荐 Parser 架构

```text
Workbook
  ↓ selectWorksheet()
Worksheet
  ↓ detectTimetableRegion()
TimetableRegion (A/B 为时间轴，C/D 为课表列)
  ↓ identifyCohortColumns()
CohortMetadata[]
  ↓ buildDaySectionMap()
row → dayOfWeek / section
  ↓ resolveMergedRange()
只读取左上角，取得 startRow / endRow
  ↓ parseCourseBlock()
一个 cell 拆成 0..n 个课程文本块
  ↓ normalizeCellText()
统一换行、空格、标点但保留 rawText
  ↓ parseCourseCell()/parseCourseLine()
课程名 + 周次片段 + 可能的行尾教室
  ↓ parseWeekExpression()
weeks[] + normalized + warning
  ↓ extractTeacher()
teacher + source confidence
  ↓ extractAcademicAdvisor()
academicAdvisor
  ↓ extractClassroom()
classroom + warning
  ↓ validateAndDeduplicateBySource()
  ↓ Course[] + warnings + metadata
```

## 必要函数

| 函数 | 是否必要 | 真实数据依据 |
| --- | --- | --- |
| `detectTimetableRegion()` | 必要 | `A1:N43` 被空样式扩张，真实区为 `A1:D43` |
| `identifyCohortColumns()` | 必要 | C/D 横向代表两个不同年级课表 |
| `buildDaySectionMap()` | 必要 | 星期在 A 列纵向分块，不是星期列 |
| `resolveMergedRange()` | 必要 | 课程时长来自纵向合并，且只能读取左上角一次 |
| `parseCourseBlock()` | 必要 | 5 个单元格各包含 3 门课程 |
| `normalizeCellText()` | 必要 | 换行、双空格、中英文标点并存 |
| `parseCourseCell()` | 必要 | 普通两行文本和多课程文本需统一输出 |
| `parseWeekExpression()` | 必要 | 11 种真实周次值及混合括号 |
| `extractTeacher()` | 必要 | 无标签姓名与“授课教师”两种格式 |
| `extractAcademicAdvisor()` | 必要 | 15 个课程项含独立导师字段 |
| `extractClassroom()` | 必要 | 教室有两种位置，且体育3缺教室 |

## 去重策略

- 只按 `worksheet + mergedRange + blockIndex` 防止重复遍历合并单元格。
- 不按星期/节次去重。
- 不按原始 cell 文本整体生成一个 Course；多课程块必须拆分。
- 可对 `{cohort, day, sections, weeks, normalizedName, teacher}` 完全相同的记录发出 `SUSPECTED_DUPLICATE`，但不要静默删除。

  | 'SUSPECTED_DUPLICATE'
  | 'MERGED_CELL_ANOMALY'

warning 应表达不确定性，而不是作为丢弃 Course 的理由。teacher 或 classroom 为空时，只要课程名、时间位置和基本周次仍可用，就应保留 Course。只有无法确定其为课程、无法确定时间位置或数据严重矛盾时才考虑不生成，并记录可定位的 parse-failure warning。

# 潜在异常

1. 工作表报告范围被空样式扩到 N 列，不能依赖矩形 used range。
2. `F22:F23` 是业务区外空合并，说明“所有 merged ranges 都是课位”这一假设错误。
3. A1 是空格而非标题，trim 后为空。
4. 周次括号存在 `（1-12周）` 与 `(1-12周）` 混用。
5. 课程名本身带括号，如 `技术日语（二）`、`综合日语（三）`；取第一个括号会截错课程名。
6. 5 个课程 cell 含 3 门课程，不能一格一课。
7. “授课教师”使用中文冒号和英文冒号两种形式。
8. “学术导师”与授课教师同一行，容易错误覆盖 teacher。
9. 教室可能紧跟周次右括号，没有空格。
10. `体育3` 中的数字不是教室，且该课程确实缺少教室。
11. 7 个空白合并课位不能生成空课程或重复记录。
12. Excel 只有星期一～五和第 1～8 节；图片时间模型包含第 9～11 节。
13. Excel 没有学期起止日期、总周数或年份全称；奇偶周展开需要外部/用户 metadata。

## 授课教师与学术导师

- `环境设计（2-5周）A7-322\n授课教师：冈田庸平  学术导师：王词光`：teacher 为冈田庸平，academicAdvisor 为王词光。

- 验证学术导师不能覆盖 teacher。

## 多课程块与同时间分周

- D8 全文应返回 3 项，不是 1 项。
- 3 项的 dayOfWeek 都为 1，startSection 都为 5，endSection 都为 8。
- 3 项名称分别为环境设计、视觉设计、角色造型。
- 3 组 weeks 分别为 2～5、10～12、13～16，互不合并。
- D24 的视觉设计应解析为 9～12 周；D32/D40 应解析为 9～11 周，防止复制上一日周次。

## merged cells

- 遍历 `D4:D5` 只能生成 1 项。
- 遍历 `C8:C11` 只能生成 1 项。
- 遍历 `D8:D11` 应按 blockIndex 生成 3 项，但不能因 4 个行坐标生成 12 项。
- 空合并 `C4:C5` 不生成 Course。
- 业务区外 `F22:F23` 不生成 Course。

## 区域与课表列识别

- worksheet dimension 为 `A1:N43` 时，`detectTimetableRegion()` 应识别业务区 `A1:D43`。
- C2/C3 应形成独立 cohort，D2/D3 应形成另一个 cohort，即使 C3 与 D3 文本相同。
- 星期六/日缺失时不得错误映射 E/F 列。
